# Branch Profile

本文件是针对当前分支的项目画像，不是通用 Harness 模板。迁移到其他项目时，必须让 AI 通过 `harness-kit/init/project-profiler.prompt.md` 重新生成，并由人 review 推断项和待确认项。

> **适用条件**：仅 feature / task / bugfix / test 等临时开发分支需要。若当前分支为 `main`、`develop` 等主干分支，不生成此文件（或写入 `# 主干分支，无需分支画像`）。
>
> 与 `project.profile.md`（全项目整体画像）互补：整体画像覆盖全仓库的技术栈、目录结构和长期约定；本文件聚焦**当前分支**的开发范围、变更影响面和即时上下文，帮助 AI 在本分支上更精准地理解当前任务边界。
